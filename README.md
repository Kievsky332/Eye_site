# Eye_site

Веб-приложение для тренировки глаз и напоминания о необходимости моргать. Сайт помогает бороться с синдромом сухого глаза и усталостью при длительной работе за компьютером, напоминая пользователю о регулярном моргании.

## Описание проекта

Этот проект представляет собой полезный инструмент для здоровья глаз. Приложение отслеживает время и через заданные интервалы напоминает пользователю о необходимости поморгать. Проект разработан как простой, но эффективный способ борьбы с напряжением глаз при работе с цифровыми устройствами.

---

## Стек технологий

- **HTML5** — семантическая разметка страницы
- **CSS3** — стилизация интерфейса и анимации
- **JavaScript (ES6+)** — логика таймеров, управление интервалами напоминаний и воспроизведение звуковых сигналов

---

## Запуск локально

Проект является полностью статическим и не требует установки зависимостей.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/Eye_site.git
   ```
2. Перейдите в папку проекта:
   ```bash
   cd Eye_site
   ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
---
# Структура проекта

```text
Eye_site/
 ├── index.html       # Основная разметка страницы и интерфейс напоминаний
 ├── style.css        # Файл стилей для оформления интерфейса
 ├── main.js          # Логика таймеров и управление напоминаниями
 ├── pip.mp3          # Звуковой сигнал для напоминания
 ├── razz.mp3         # Дополнительный звуковой эффект
 ├── ico.png          # Иконка глаза для визуального оформления
 ── LICENSE          # Лицензия проекта (MIT)
```
